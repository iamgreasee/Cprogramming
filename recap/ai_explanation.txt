01 — Hello World

#include <stdio.h> is a preprocessor directive that tells the preprocessor to include the contents/interface of the standard input/output library before the actual compilation of the program. This gives the program access to functions such as printf() and scanf(). Every C program needs an entry point, which is the main() function, and execution begins there. printf() is used to output text to the terminal, while return 0 at the end of main() indicates that the program finished successfully. The basic structure of a C program is therefore roughly headers → main() → statements → return value.

02 — Variables

A variable is a named location in memory used to store some value. In C, unlike dynamically typed languages such as Python, the type of the variable needs to be specified when it is declared. For example, int age = 18; declares an integer called age and gives it the initial value 18. Different types are used for different kinds of data, such as int for integers, float and double for decimal numbers, char for individual characters and bool for true/false values. The type determines how the compiler interprets the bytes associated with that variable and what operations can be performed on it.

03 — Format Specifiers

Format specifiers are used with functions such as printf() and scanf() to indicate what type of data is being output or expected. For example, %d is commonly used for an int, %f for floating point values, %c for a character and %s for a string. Instead of putting a variable directly inside a string like you might in Python, you put a format specifier where the value should appear and then provide the corresponding variable as another argument. For example, printf("You are %d years old", age); tells printf() to replace %d with the value stored in age. Format specifiers therefore provide a way for C's functions to know how the raw data should be interpreted.

04 — Arithmetic Operators

C provides the usual arithmetic operators for manipulating numerical values. Addition, subtraction, multiplication and division are represented by +, -, * and /, while % gives the remainder after integer division. Operators can be combined to perform more complicated calculations, and parentheses can be used to control the order in which operations occur. One thing to remember is that integer division behaves differently from decimal division: dividing two integers produces an integer result, meaning any fractional part is discarded. Arithmetic operators can be used with variables, constants and expressions and are one of the basic building blocks of practically every program.

05 — User Input

User input can be taken in several ways, with scanf() and fgets() being two important examples. scanf() uses a format specifier to determine what type of value it should read and generally requires the memory address of the variable where the input should be stored, which is why you commonly see &age. fgets() is particularly useful for strings because it reads a sequence of characters into a character array and takes the size of that array to prevent it from writing beyond the available memory. stdin represents standard input, normally the keyboard. One important difference is that fgets() can read whitespace, so it can capture an entire sentence or full name rather than stopping at the first space.

06 — Math Functions

The math.h header provides various functions for performing mathematical operations that would otherwise be tedious to implement yourself. Functions include pow() for raising a number to a power, sqrt() for square roots, rounding functions such as ceil() and floor(), and various trigonometric functions. There are also functions for finding absolute values, although the exact function depends on the type of number being used. The important idea here isn't necessarily memorising every mathematical function, but understanding that C's standard libraries provide prewritten functionality that can be included and called when needed rather than having to implement everything from scratch.

07 — If Statements

if statements allow a program to make decisions based on whether a condition evaluates to true or false. An if block executes when its condition is true, while else if allows additional conditions to be tested and else provides a fallback when none of the preceding conditions are satisfied. Conditions commonly involve comparison operators such as ==, >, <, >= and <=. This gives programs the ability to behave differently depending on the values of variables or the input provided by the user. Multiple conditions can also be combined using logical operators.

08 — Switches

A switch statement provides another way of dealing with multiple possible values of a single expression. Instead of repeatedly writing if and else if statements to compare one variable against several specific values, a switch can contain multiple case labels. When the value being switched on matches a case, the code associated with that case is executed. break is normally used to stop execution from continuing into the following cases. A default case can be used as the equivalent of a fallback when none of the available cases match. Switches are particularly useful when a program has a fixed set of possible choices.

09 — Nested If Statements

Nested if statements are simply conditional statements placed inside other conditional statements. They are useful when one decision depends on another decision already being true. For example, a program could first check whether someone is old enough to enter somewhere and then, inside that block, check whether they have a ticket. This allows increasingly specific conditions to be tested. However, deeply nesting conditions can make code difficult to read, so logical operators or restructuring the conditions can sometimes be preferable.

10 — Logical Operators

Logical operators allow multiple conditions to be combined into a single expression. && represents logical AND, meaning both conditions must be true; || represents logical OR, meaning at least one condition must be true; and ! represents logical NOT, which reverses a condition's truth value. These operators are particularly useful inside if statements because they allow several requirements to be expressed without creating a separate conditional statement for every possibility. For example, if (age >= 18 && hasID) means that both conditions must be satisfied before the code runs.

11 — Functions

Functions are reusable blocks of code that perform a particular task. Instead of writing the same code repeatedly, the code can be placed inside a function and then executed by calling that function. Functions can accept values through parameters, allowing them to operate on data supplied by the code that called them. Variables created inside a function generally belong to that function's scope, which means another function cannot simply access them directly. Functions therefore provide a way to organise a program into smaller, more manageable pieces and allow information to be passed between different parts of the program.

12 — Return Keyword

The return keyword is used to send a value back from a function to the location where that function was called. A function's return type specifies what kind of value it is expected to return. For example, a function with a return type of double could take a number and return its cube. The returned result can then be stored in another variable or used directly in an expression. return is also used in main() to provide the operating system with an exit status, where 0 conventionally indicates successful execution and a nonzero value generally indicates an error.

13 — Variable Scope

Variable scope determines where a variable can be accessed within a program. A variable declared inside a function or block generally only exists within that particular scope and cannot simply be accessed from elsewhere. This is why a variable created inside main() cannot normally be directly accessed by another function. Values can instead be passed between functions using parameters and return values. Understanding scope is important because it prevents different parts of a program from accidentally interfering with variables belonging to other parts of the program and helps keep data local to where it is actually needed.

14 — Function Prototypes

A function prototype tells the compiler that a function exists before the compiler reaches the actual definition of that function. It specifies the function's return type, name and parameters but does not contain the function's implementation. For example, int getMax(int a, int b); tells the compiler that there will be a function called getMax which takes two integers and returns an integer. This means the actual function can be written later in the file while still being called from main(). Function prototypes are particularly useful for keeping the main() function near the top of a program while placing the implementations of its functions elsewhere.

15 — While Loops

A while loop repeatedly executes a block of code as long as a specified condition remains true. The condition is checked before each iteration, meaning the code inside the loop might not execute at all if the condition is initially false. Loops are useful when something needs to happen repeatedly but the exact number of repetitions isn't necessarily known beforehand. For example, a program could continue asking the user for input until they enter a particular value. The loop must eventually have some way of making its condition false, otherwise it can continue indefinitely.

16 — For Loops

A for loop is another type of loop and is particularly convenient when the number of iterations is controlled by a counter. A for loop normally contains three parts: an initialisation, a condition and an update. For example, for (int i = 0; i < 10; i++) creates a counter, continues while the counter is less than ten and increments it after each iteration. This makes for loops particularly useful for iterating through arrays or performing an operation a known number of times. Functionally, they can accomplish many of the same tasks as while loops, but the syntax makes the loop's counter logic more compact.

17 — Break and Continue

break and continue provide ways of altering the normal behaviour of a loop. break immediately exits the loop entirely, regardless of whether the loop's original condition would have allowed another iteration. continue instead skips the remainder of the current iteration and moves on to the next iteration. These can be useful when a loop needs to stop early after finding something or when certain values should be ignored. They are especially useful when combined with conditions inside loops, although excessive use can sometimes make the flow of a program harder to follow.

18 — Nested Loops

A nested loop is a loop placed inside another loop. Every time the outer loop performs one iteration, the inner loop can execute all of its iterations. This is particularly useful when dealing with two dimensional data, such as rows and columns in a grid. For example, the outer loop could represent each row while the inner loop represents each column. Nested loops can also be used for generating patterns or comparing multiple values against one another. The number of operations can increase quickly with nested loops, so understanding how many times each loop executes is important.

19 — Random Numbers

C's random number functionality can be used to generate pseudo random values. The rand() function produces a number from a deterministic sequence, which means it isn't truly random in the physical sense. The sequence can be changed by providing a different seed, commonly using srand(). Random values can also be constrained to a particular range using the modulus operator and arithmetic. This is useful for things such as games, simulations and randomly selecting options. The important distinction is that ordinary C random number generation is designed for general programming rather than cryptographically secure randomness.

20 — Arrays

An array is a collection of multiple values of the same data type stored together in memory. Instead of creating separate variables for every value, a single array can contain many elements that are accessed using an index. C arrays use zero based indexing, meaning the first element is at index 0. Arrays have a fixed size when normally declared, and accessing an element involves calculating its position relative to the beginning of the array. Character arrays are also used to represent strings in C, with a null character '\0' marking the end of the string. Arrays therefore introduce the idea of storing related data in contiguous memory.

21 — Ternary Operator

The ternary operator provides a compact way of writing a simple conditional expression. It uses the form condition ? value_if_true : value_if_false. Instead of writing a full if and else block when the program simply needs to choose between two values, the ternary operator can perform the selection in one expression. For example, age >= 18 ? "adult" : "minor" chooses one of two strings depending on the condition. It is useful for simple decisions, although complicated ternary expressions can become difficult to read.

22 — Typedef

typedef allows a new name to be created for an existing data type. This can make declarations shorter or easier to understand, especially when working with structs. For example, instead of repeatedly writing struct Person, a typedef can allow the type to simply be referred to as Person. typedef does not actually create a completely new underlying type; it creates another name for an existing type. It is mainly a tool for making code cleaner and easier to work with, particularly when declarations would otherwise become cumbersome.

23 — Enums

An enumeration, or enum, is a user defined type consisting of a set of named integer constants. Instead of using unexplained numbers such as 0, 1 and 2 to represent different states, an enum can give those values meaningful names such as MENU, PLAYING and QUIT. This makes code easier to understand because the purpose of a value is visible from its name. Underneath, the enumeration values are represented as integers, but the named constants make them much more readable when used in conditions and switches.

24 — Structs

A struct allows multiple pieces of related data, potentially of different types, to be grouped together into a single object. For example, a Person struct could contain an integer for age, a character array for a name and a floating point value for height. Each member of the struct can be accessed using the . operator when working with an actual struct variable. Structs are useful because they allow a program to represent more complicated objects rather than keeping every piece of related information in separate variables. An array of structs can then be used to store many objects of the same structure.

25 — Pointers

A pointer is a variable whose value is the memory address of another object. Instead of storing the actual value directly, a pointer stores where that value can be found in memory. The & operator obtains the address of a variable, while * can be used to dereference a pointer and access the value at the address it contains. Pointers are particularly important in C because they allow functions to modify variables outside their own local scope, allow arrays and strings to be manipulated efficiently and form the basis of dynamic memory allocation. A pointer can also point to a struct, in which case the -> operator can be used to access its members.

26 — Writing Files

File writing allows a C program to store information outside of its own running memory. fopen() opens a file and returns a pointer to a FILE structure, which is used by the C standard library to keep track of the open file. The mode determines what the program intends to do with the file, such as "w" for writing. Functions such as fprintf() can then write data to the file using that FILE * pointer. Once the program has finished with the file, fclose() should be called to close it and ensure that buffered data is properly written. The important concept here is that FILE * is a reference to the library's information about an open file, not the contents of the file itself.

27 — Reading Files

Reading files is essentially the opposite of writing them: the program opens an existing file and retrieves its contents into memory. fopen() can be used with modes such as "r" to open a file for reading. Functions such as fgets(), fscanf() or other file reading functions can then retrieve information from the file through the FILE * returned by fopen(). The program needs to account for the possibility that the file does not exist or cannot be opened, which is why checking whether the returned pointer is NULL is important. Files should also be closed with fclose() once the program has finished reading them.

28 — malloc

malloc() is used to dynamically allocate memory while a program is running. Unlike an ordinary local array whose size is normally determined when the program is compiled, dynamically allocated memory comes from the heap and can be requested when the program actually needs it. malloc() takes the number of bytes required and returns a pointer to the allocated memory. Because the memory returned by malloc() has not been initialised, its contents should not be assumed to contain useful values. The programmer is responsible for eventually releasing memory obtained with malloc() using free() so that it does not remain allocated unnecessarily.

29 — calloc

calloc() is another function for dynamically allocating memory, but unlike malloc(), it takes the number of elements and the size of each element and initialises the allocated memory to zero. This makes it particularly convenient when creating arrays dynamically. For example, dynamically allocating space for ten integers can be done by asking calloc() for ten elements of sizeof(int) bytes each. Like malloc(), calloc() returns a pointer to the allocated memory and that memory eventually needs to be released using free(). The main conceptual difference is therefore allocation plus zero initialisation rather than allocation with uninitialised contents.

30 — realloc

realloc() is used to change the size of a block of dynamically allocated memory. This is useful when the program initially allocates some amount of memory but later discovers that it needs more or less space. realloc() takes the existing pointer and the new requested size and attempts to resize the allocation. The memory may sometimes be moved to a different location if there isn't enough room to expand it where it currently is, which is why the returned pointer needs to be handled carefully. Like other dynamically allocated memory, the resulting allocation must eventually be released
